# Goofy Ball — UI-концепт

> Макеты экранов — референс раскладки и логики, а не финальный арт. Стиль и палитра — в [`art-direction.md`](art-direction.md).
> Экран рисуется в 1600×900 (горизонтальный телефон), на листах — в рамке телефона.

## Принципы
1. Одна главная кнопка «ИГРАТЬ» — 1 тап до поиска матча.
2. У всего есть значение по умолчанию (последний выбор запоминается) — можно ничего не настраивать.
3. Глубина меню ≤ 2: вкладка → экран. Модалки — только для коротких выборов.
4. Главное действие — справа снизу, под большой палец. Кнопки ≥ 88 px.
5. В матче почти нет UI: счёт, пауза, 2 кнопки. Остальное — в мире (ники над блобами, плашки событий).
6. Цвет = смысл: жёлтый — главное действие, циан — вторичное, маджента — поделиться/соц., красный — выход/опасность, фиолетовый — бафы и реклама за награду.
7. Иконка + 1–2 слова: читается без звука и почти без знания языка.
8. Один макет для тача, мыши и геймпада: фокус-рамка и хоткеи на PC.
9. Покупки не мешают игре: нет попапов перед матчем, нет рекламы в ранговых, только косметика.
10. Смешной момент сохраняется сам («★ Момент сохранён») → одна кнопка «Поделиться» в итогах.

## Навигация
- **Главный путь:** Загрузка → Главная → Поиск → VS → Матч → Итоги. Первый запуск: Загрузка → Обучение (матч с AI с подсказками) → Главная.
- **С главной:** «Против AI» (один экран настроек) и «С другом» (модалка: создать комнату / войти по коду).
- **Нижняя навигация:** Играть · Блоб · Магазин · Рейтинг (лидерборд и кубки). **Шапка:** профиль, батл-пасс, валюта, настройки.
- **Итоги:** Реванш → VS, Дальше → Главная, Поделиться → Клип.

## Открытые вопросы
- Ранговые доступны сразу или с уровня N (защита новичков)?
- Валюта: одна (монеты) или две (монеты + кристаллы за деньги)?
- Выход из онлайн-матча: сразу поражение или бот доигрывает за игрока?
