# Goofy Ball
Godot 4.7 2D online slime volleyball (Blobby Volley + chaotic buffs). Mobile first, then web/PC.
Technical approaches mirror `GGamezebo/quizmatik` (structure, HFSM, scene isolation, Resource events, editor-first UI).
